# Se repérer dans l’interface

Le [Manuel utilisateur](../UserManual.md) décrit les panneaux du débogueur, les raccourcis et les passages entre Mémoire, Périphériques, Pile, Surveillance et IDE. Il est également accessible dans **Aide → Manuel utilisateur**.

La disposition initiale présente les cœurs et leurs piles à gauche, les suivis à droite, et la mémoire et les périphériques au centre. L’assembleur rejoint le centre quand l’IDE est fermé. Le bouton **Console** replie ou déplie les outils en dessous. Utilisez les barres de titre et les séparateurs pour organiser les panneaux. **Vues → Fenêtres flottantes** permet de les détacher. **Ctrl+Maj+0** rétablit la disposition initiale.
